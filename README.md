# Zudio Store Sales Performance Analysis

##  Overview
This project analyzes store sales performance across different categories, cities, and store types to uncover operational insights and business opportunities.

##  Tools Used
- SQL: Data cleaning and analysis
- Tableau: Dashboard creation and visualization
- Excel: Preprocessing and validation

##  Data Cleaning
- Checked and removed duplicates
- Standardized categorical fields (City, Store Type)
- Added Month column for trend analysis

##  Analysis Queries
- Monthly Revenue Trends
- Category-wise Revenue Distribution
- Store Type Revenue Comparison
- Parking Impact on Sales
- Top Performing Cities for Kid’s Category

##  Key Insights & Findings
1. **Consistent Monthly Performance:**  
   Revenue was stable through the year, with a dip in December (post-festival slowdown).

2. **Category Performance:**  
   - Kid’s category led total sales across cities.  
   - Men’s and Women’s followed steadily.

3. **Store Type Contribution:**  
   Rented stores outperformed owned ones, contributing a higher share of revenue.

4. **Parking Availability Impact:**  
   Stores with parking contributed over 50% of total sales, proving the value of accessibility.

5. **Top Cities for Kid’s Category:**  
   Jammu, Indore, and Hyderabad led in revenue contribution.
